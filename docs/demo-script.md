> 준비: 노트북 브라우저 1440px 이상에서 `https://<cloud-run-url>/demo` 를 미리 한 번 열어 둔다 (무료 등급 콜드스타트를 깨우기 위해). "가상 집을 준비하는 중입니다"가 사라지면 준비 끝. 같은 장면은 README GIF(`docs/figures/demo-30s.gif`)로도 있다.

## 막혔을 때
- 브로커가 없으면 데몬은 종료 코드 3으로 끝난다. `mosquitto -c deploy/mosquitto-dev.conf` 를 다시 띄운다.
- 앱에 알림이 안 보이면 `.env` / `web/.env.local` 의 anon 키가 `supabase status -o env` 값과 같은지 본다.
- 라이브가 어려우면 위 그림 6장을 순서대로 보여 주면 같은 이야기가 된다.

## 말하지 않는 것
응급 자동 신고, 영상·음성 수집은 이 제품이 하지 않는 것이다. 질문이 나오면 "가족이 판단한다"로 답한다.
